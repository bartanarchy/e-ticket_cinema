# 🎬 CinemaTicket - E-Ticket Cinema System

A web-based cinema e-ticket application built with PHP and MariaDB/MySQL.

## Tech Stack
- PHP 8.x
- MariaDB / MySQL
- Apache (Laragon)
- Bootstrap 5.3
- HTML, CSS, JavaScript

## Installation Guide

### 1. Clone Repository
```bash
git clone https://github.com/username/e-ticket_cinema.git
```

### 2. Move to Laragon www folder
Place the project folder in `C:\laragon\www\e-ticket_cinema`

### 3. Download Bootstrap
Download Bootstrap 5.3 at https://getbootstrap.com/docs/5.3/getting-started/download/

Extract and place the files:
- All CSS files = `assets/css/`
- All JS files = `assets/js/`

### 4. Import Database
- Open phpMyAdmin at `localhost/phpmyadmin`
- Create a new database named `cinema_ticket`
- Import the `cinema_ticket.sql` file located in the project folder

### 5. Run the Application
Open your browser and go to `localhost/e-ticket_cinema`
